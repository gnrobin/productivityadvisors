LWC Productivity Components

Most Sales Cloud orgs make reps leave the record to get anything done. These thirteen Lightning Web Components put the answer, and the next action, in place on the page a rep or manager is already looking at. Each one runs on standard objects, drops onto a Lightning page, and most take a week or less to build.

What In-Place Means

A standard record page shows fields and related lists. It rarely tells a rep whether the deal is healthy, what is missing, or what to do next, so that work moves to reports, spreadsheets and side tools. An in-place component answers one question and offers one action right where the question comes up.

Every component below follows the same rules: it reads data the org already has, it writes back to standard fields so reports keep working, and its thresholds live in Custom Metadata so an admin can tune them without a developer.
